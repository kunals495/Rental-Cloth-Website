# 👗 Rental Cloth Website

A web application that allows users to **rent clothes for special occasions** (weddings, parties, festivals, etc.) and return them after use.


## 🌐 Live Demo
https://github.com/user-attachments/assets/d3af7953-6878-48d4-a1c9-bd7fe9b1f5ba



## 🛠️ Tech Stack

**Frontend**: HTML5, CSS3  
**Backend**: PHP  
**Database**: MySQL  
**Payment Integration**: Razorpay



## 📦 Features

- 👕 Browse clothing items based on categories (e.g., Traditional, Western, Wedding)
- 📄 View detailed descriptions, prices, and rental duration for each item
- 🛒 Add items to cart and proceed to checkout
- 💳 Payment gateway integration for secure online payment
- 🗓 Select rental duration and return date
- 👤 User login & registration system
- 🧾 Order history and rental status tracking
- 🔐 Admin dashboard to manage inventory and orders (optional)
